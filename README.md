# BookStatistic - AI-Powered Book Genre Analysis

> Облачный сервис для глубокого анализа литературных предпочтений с использованием NLP и машинного обучения.  
> **Не просто "какие книги вы читаете", а "что именно в книгах вас привлекает".**

## О проекте

BookStatistic решает проблему поверхностной жанровой классификации книг. Традиционные сервисы определяют жанр книги по метаданным (фэнтези, детектив, роман), но редко учитывают, что внутри "фэнтези" могут быть элементы детектива, романтики или хоррора. Этот продукт предназначен для того, чтобы на основе прочитанных пользователем книг (по содержанию) определять его предпочтения и на основании этого предлагать материал, который позволит определять рекомендации.

**Как это работает:**
1. Пользователь добавляет книги в свою библиотеку и отмечает прогресс чтения
2. Система извлекает текстовое содержание книг
3. Предобученная модель SBERT создает эмбеддинги текста (768-мерные векторы)
4. Кастомный классификатор на основе логистической регрессии определяет скрытые жанры и поджанры
5. Результаты агрегируются в персональный профиль читательских предпочтений

**Пример:**  
Пользователь читает "Ведьмака" Анджея Сапковского. Официальный жанр - фэнтези, но BookStatistic определит:
-  Героическое фэнтези: 0.85
-  Детективные элементы: 0.72
-  Романтическая линия: 0.61
-  Темное фэнтези: 0.58
-  Моральные дилеммы: 0.83
